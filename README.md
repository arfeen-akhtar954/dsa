# Data Structures & Algorithms Practice

A focused Python-based repository for practicing core computer science fundamentals and preparing for technical interviews, coding assessments, and software engineering roles.

## Overview

This repository contains interview-style problem-solving exercises covering foundational data structures and algorithms commonly tested in technical screening rounds. The goal is to strengthen problem-solving patterns, improve code clarity, and build confidence in writing efficient Python solutions.

## Why this matters for jobs

Technical interviews often evaluate:

- problem-solving ability
- algorithmic thinking
- time and space complexity analysis
- clean, readable implementation
- comfort working with common coding patterns

This repository helps practice those skills in a structured, reusable way and is suitable for candidates targeting roles such as:

- Software Engineer
- Backend Engineer
- Data Engineer
- QA Automation Engineer
- Technical Interview Preparation

## Repository structure

- [arrays.py](arrays.py) — array fundamentals, searching, sorting checks, duplicates, frequency analysis, and element comparisons.
- [binaryseach.py](binaryseach.py) — binary search patterns, lower/upper bound logic, rotated arrays, and search-on-answer techniques.
- [string.py](string.py) — string manipulation, anagrams, palindrome checks, prefix logic, and common interview problems.
- [linkedList.py](linkedList.py) — basic linked list traversal and head deletion operations.

## Skills practiced

- Data structures: arrays, strings, linked lists
- Algorithms: binary search and pattern-based searching
- Complexity analysis: O(n), O(log n), and related trade-offs
- Problem decomposition and edge-case thinking
- Python implementation for interview-style questions

## How to use

Each file contains commented-out example problems. Uncomment the example you want to test, then run the file with Python:

```bash
python arrays.py
python binaryseach.py
python string.py
python linkedList.py
```
